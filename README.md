# recipe-tracker

Recipe tracker that scales ingredient quantities. Native iOS app and a web app, synced through one backend. Code is public. Recipe data is private to its owner unless shared.

**Status:** pre-plan. Requirements are being gathered in [`docs/RAMBLE.md`](docs/RAMBLE.md).

## Layout

| Path | What |
|---|---|
| `apps/ios` | SwiftUI app (empty) |
| `apps/web` | Web app (empty) |
| `supabase/` | Migrations and row-level security policies |
| `docs/` | Ramble, decisions, plan |

See [`docs/DECISIONS.md`](docs/DECISIONS.md) for what's been settled so far.
